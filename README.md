# Система управління електронною бібліотекою та каталогом книг

Навчальний вебзастосунок електронної бібліотеки, створений на React, TypeScript
і Vite. Інтерфейс каталогу демонструє список книг і доступних примірників та
дозволяє позначити книгу заброньованою у межах поточної сторінки.

## Архітектура

```text
React UI
├── pages/       Сторінки застосунку
├── components/  Спільні компоненти інтерфейсу
├── features/    Функціональні модулі предметної області
│   ├── auth/       Автентифікація та ролі користувачів
│   ├── catalog/    Каталог, пошук і перегляд книг
│   ├── borrowing/  Бронювання та обіг примірників
│   └── admin/      Адміністрування бібліотеки
├── hooks/       Повторно використовувана логіка React
├── services/    Інтеграції з API та зовнішніми сервісами
├── store/       Спільний стан застосунку
├── types/       Спільні типи TypeScript
└── assets/      Статичні зображення та ресурси
```

### Основні модулі

- **`auth`** — вхід і вихід користувачів, управління сесією та розмежування
  ролей читача й бібліотекаря.
- **`catalog`** — перелік книг, пошук і перегляд бібліографічних даних та
  інформації про доступні примірники.
- **`borrowing`** — бронювання книг, облік видачі та повернення примірників.
- **`admin`** — інструменти бібліотекаря для керування каталогом, користувачами
  й операціями бібліотеки.

Папки модулів підготовлені для подальшої розробки; поточний навчальний екран
показує мокові дані каталогу, а бронювання оновлює локальний стан сторінки.

## Структура `src/`

- **`assets/`** — локальні зображення, іконки та інші статичні ресурси.
- **`components/`** — повторно використовувані UI-компоненти, зокрема `Button`
  і `BookCard`.
- **`features/`** — код, згрупований за функціональними модулями: `auth`,
  `catalog`, `borrowing` і `admin`.
- **`hooks/`** — власні React hooks для повторного використання стану та
  поведінки між компонентами.
- **`pages/`** — сторінки, що формують основні екрани застосунку.
- **`services/`** — клієнти API та логіка взаємодії із сервером.
- **`store/`** — спільний стан, що використовується кількома функціями чи
  сторінками.
- **`types/`** — спільні типи та інтерфейси предметної області, зокрема `Book`
  і `User`.

## Path Aliases

Аліас `@/` вказує на папку `src/`. Він налаштований для TypeScript і Vite,
тому замість відносних шляхів можна використовувати короткі імпорти:

```tsx
import BookCard from '@/components/BookCard/BookCard'
import type { Book } from '@/types/book'
import CatalogPage from '@/pages/CatalogPage'
```

## Встановлення та запуск

Потрібен встановлений Node.js і npm.

```bash
npm install
npm run dev
```

(`http://localhost:5173`).

## Перевірка проєкту

```bash
npm run lint
npm run build
```

ESLint налаштований у `eslint.config.js` для TypeScript, React Hooks і правил
сумісності з React Refresh. Форматування описане у `.prettierrc`.
